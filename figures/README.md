## Interpretation cautions

- Shared memory removes the kernel payload-copy path, but the producer still performs a userspace `memcpy` into the ring.
- Streaming per-message latency can contain queue residence time; ping-pong RTT/2 latency cannot.
- A lower cache-miss rate is a correlation. It does not, on its own, prove that cache-line alignment caused the complete throughput difference.
- The image `flamegraphs/final_io_uring.jpg` is a captured profile artifact, not evidence of SQPOLL. The profiled standalone harness initializes `io_uring` with `flags=0`.
- Missing or unsupported performance counters must not be interpreted as zero.

## Regenerating figures

From the repository root:

```bash
python3 scripts/ablation_analysis.py \
  --data data/ablation_results.csv \
  --perf data/ablation_perf_stat.txt \
  --output figures/ablation

python3 scripts/pingpong_analysis.py \
  --data data/pingpong_results.csv \
  --output figures/pingpong

python3 scripts/generate_visualizations.py
```

Before publication, verify that every caption matches the same CSV snapshot and environment record used by the current `report.tex`.
